## しきい値付きの判定のまとめ

数値はすべて上の 2 つの節 (しきい値付きの判定) の表による. |ERP の差| ≤ 0.1% と P の比 0.95〜1.05 を同等とする.

- **パート B の 5 区分** (35 マス): P1 only (protect) n_target=10 は 改善 7, 同等 21, 棄却のみ改善 3, 引き換え 0, 悪化 4.
  しきい値を入れると, しきい値なしで「改善」だった 26 マスの多くが「同等」に移る (ERP の差が 0.1% 未満).
  悪化の 4 マスは α=10 の r1 ≤ 17.8 (ERP の最大の悪化 +2.32%, α=10, r1=0.1).
  P1 only (protect) n_target=20 は 改善 9, 同等 3, 棄却のみ改善 0, 引き換え 23, 悪化 0.
  P2 only γ=3 は 改善 3, 同等 3, 棄却のみ改善 0, 引き換え 6, 悪化 23. P2 only γ=10 は 改善 2, 同等 2, 引き換え 0, 悪化 31.
- **パート A の β を 2 倍にしたとき**: P が P_ref を 5% より多く超える組は 12 組中 8 組 (+6.8%〜+195.1%;
  最大は A_rhoB0.6 r1=3.16 の P1 only (protect) で P の比 2.951). 超えないのは B_alpha1 r1=3.16 の P1 only (protect)
  (0.671) と B_alpha10 r1=17.8 の P1+P2 (protect) (0.978), 5% 以内は A_rhoB0.8 r1=17.8 の P1+P2 (protect) (1.021) と
  B_alpha10 r1=17.8 の P1 only (protect) (1.016).
- しきい値なしの判定と比べ, パート A で悪くなる範囲はほとんど変わらない. 変わるのは, B_alpha1 r1=3.16 の
  P1 only (protect) の n_target=20 (ERP の差が 0.1% 以内になり悪くない側へ), A_rhoB0.8 r1=17.8 の P1+P2 (protect) の
  β×2 (P の比 1.021 で同等), B_alpha10 r1=17.8 の 2 系列 (P は β×10 でしか悪くならない, など) である.
