## まとめ

数値はすべて上の表による. 改善 = −(相対差), 区分のしきい値は 0.1%.

- **(a)** ERP 最小点のブロッキング確率は, C1 と C4 で Predictive の多くの系列が Base より高い
  (C1: P1 only (protect) 2.35 倍, P1+P2 (protect) 3.07 倍, P2 only 1.85 倍, P1+P2 1.98 倍;
  C4: 1.84〜2.48 倍). C2, C3, C5 では 1.18 倍以下 (C2 の保護ありは 0.96〜0.97 倍で低い).
- **(b)** Base と同じ信頼性 (P ≤ P_ref) では, Base より良い (改善 > 0.1%) のは
  C1 の P1+P2 (protect) 0.81%, P1 only 0.14%, P1 only (protect) 0.11%,
  C2 の P1 only (protect) 0.32%, P1+P2 (protect) 0.32%, P1+P2 0.21%,
  C3 の P1 only (protect) 0.28%, C5 の P1+P2 (protect) 0.55%, P1+P2 0.54%, P2 only 0.53% である.
  C4 では改善する系列がない (最大 0.07%). C1 の P1 only (protect) は ERP だけでは 1.16% の改善だったが,
  ブロッキング確率を Base 以下に抑えると 0.11% に縮む (ERP 最小点の P が Base の 2.35 倍だったため).
- **(c)** C2 は Base も全系列も P ≤ 1e-2 を満たせない (Base の P_ref = 0.129). ε=1e-4 では,
  C1 で改善するのは P1+P2 (protect) (0.12%) だけで, 他の系列は Base より悪い (+0.37%〜+0.69%).
  C4 では ε=1e-4 で改善する系列がない. C3 と C5 は P_ref が 1e-4 未満なので (b) と同じ結果になる.
- **(d)** 3 指標では, C1 で P1+P2 (protect) が支配する Base の点は 31/92 (2 指標では全域 92/92),
  C5 で P1+P2 は 112/112 (全域のまま) である.
- **(e)** (Cost/λ_eff)×E[W] の最小値は ERP とほぼ同じ傾向である
  (C1 の P1 only (protect) −1.07%, P1+P2 (protect) −1.06%; C2 の保護ありは −0.70%, −0.73%).
- **ERP だけの判定から区分が変わった系列** は 10 個: C1 の P2 only と P1+P2, C4 の P2 only, P1 only (protect),
  P1+P2, P1+P2 (protect) が「改善 → 同等」, C3 の P2 only, P1 only, P1+P2 が「同等 → 悪化」,
  C2 の P2 only が「改善 → 同等」(0.11% → 0.10% で, しきい値の境目).
- 注意: Predictive の系列は β を 13 点 (と範囲を広げた点) でしか計算していないので, (b)(c) の最良点は
  13 点の格子の点であり, 格子の間に ERP の低い点がありうる (Base は 121 点). したがって (b)(c) の
  Predictive の改善は小さめに出る側の評価である.
