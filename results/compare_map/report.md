# 比較の地図 (α=0.005, Base と Predictive)

results/compare_map/compare_map_rhoB<ρ_B>.csv から scripts/compare_map.py --report で生成.

固定と定義: c=20, K=200, b=5, 1/mu=1, delta=0.6, alpha=0.005 (1/alpha=200), rho=rho_B/1.6, sigma=alpha/r1, r1 は [0.1, 100] の対数 5 点. 値は ERP の改善率 (Base の ERP 最小値に対する, P_block <= P_ref を満たす Predictive の ERP 最小値の減少率) [%]. 下の括弧は最良点の (n_target, gamma). 灰色は改善率 0.1% 以下 (同等). Predictive は保護あり, beta, n_target in {0,5,10,15,20}, gamma in {1,3,10,30,100,1000} を最適化.

主な基準: P_ref = Base の ERP 最小点の P_block_arrival_stable. P_block_arrival_stable ≤ P_ref を満たす点 (Predictive の全点と, (n_target, γ)=(0, 1) とみなした Base の全点) の中の ERP 最小点を Predictive の最良点とする. 改善率 = (Base の ERP − Predictive の ERP) / Base の ERP. 改善率 > 0.1% を「改善」, それ以下を「同等」とする.
