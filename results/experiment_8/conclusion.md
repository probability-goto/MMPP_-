## まとめ

以下の数値はすべて上の表 (experiment_8_<行>.csv から計算) による. 改善 = −(ERP の相対差).

**改善が 0.5% を超えるマス.** 3 系列のいずれかで改善が 0.5% を超えるのは 35 マス中 13 マスで,
ほぼ r1 ≥ 17.8 の列に集まる. 例外は α=1 の r1=3.16 (P1 only (protect) 3.79%, P1+P2 (protect) 1.56%,
P2 only 0.50%) と, ρ_B=0.6 の r1=3.16 (P1 only (protect) 1.24%) である.
最大は P1 only (protect) の 3.79% (地図 B, α=1, r1=3.16), P2 only の 2.69% (α=0.005, r1=17.8),
P1+P2 (protect) の 2.83% (α=0.005, r1=17.8).
地図 A では, ρ_B=0.6 と 0.8 の r1 ≥ 17.8 で改善があり (最大 2.81%, ρ_B=0.8, r1=17.8, P1 only (protect)),
バースト中に容量が足りない ρ_B=1.12 では 0.5% を超えるマスがない (最大 0.46%, r1=3.16, P1+P2 (protect)).
地図 B では, α ≤ 0.1 の行は r1 ≥ 17.8 でだけ改善し (2.08%〜2.90%), r1 ≤ 3.16 ではどの系列も 0.28% 以下である.
α=1 の行は r1 ≥ 3.16 で改善し, α=10 (セットアップがサービスの 1/10) の行は P1+P2 (protect) の r1=17.8 (0.51%)
を除いて 0.5% 以下である.

**r1=0.1 の列.** 7 マス × 3 系列の 21 組のすべてで改善は 0.5% 以下である. ただし 0 ではなく,
改善が 0.1% を超える組が 3 個ある (α=1 の P1 only (protect) 0.40% と P1+P2 (protect) 0.17%,
α=0.1 の P1 only (protect) 0.28%). 位相が短い領域で位相の情報の価値がほぼないことは確かめられた.

**地図 B での α の傾向 (仮説の検証).** 「セットアップが長い (α が小さい) ほど P1 only (protect) の改善が
小さくなる」という傾向は **ない**. 単調になる r1 はなく, 改善が大きい r1 ≥ 17.8 では逆に,
α が小さいほど改善が大きい: r1=17.8 で α=0.005, 0.02, 0.1, 1, 10 の順に 2.90%, 2.83%, 2.81%, 2.24%, 0.04%,
r1=100 で 1.89%, 1.84%, 1.64%, 0.60%, 0.02% (どちらも log10 α との Spearman の順位相関 −1.00).
α ≤ 0.1 では改善は α にほとんどよらず, セットアップがサービスより速い α=10 で消える.
r1 ≤ 3.16 では, α ≤ 0.1 の改善は 0.28% 以下で, α=1 でだけ大きい (0.40%, 0.42%, 3.79%).
実験 7 の C1 (α=0.1) と C4 (α=0.005) はどちらも r1=5 で, 改善が 0 付近から 3% 近くまで変わる
r1=3.16 と 17.8 の間にある. 改善が立ち上がる r1 が α によって違えば C1 と C4 の差が説明できるが,
r1 の格子が粗く, この地図からは判定できない. 判定には r1 ∈ (3.16, 17.8) を細かく取る必要がある.

**p1_fire_rate と 1/(1+1/r1) の相関.** P1 only (protect) の ERP 最小点 (35 マス) で,
p1_fire_rate と 1/(1+1/r1) の Pearson の相関係数は −0.200 である. p1_fire_rate は単位時間あたりの率で
σ (=α/r1) に比例する成分を含むので, 位相 0→1 の遷移 1 回あたりの発動確率 p1_fire_rate/(σ ϖ₀) にすると
+0.821 になる. ただし発動確率は 1/(1+1/r1) の曲線には沿わず, r1 ≤ 0.562 では 14 マスすべてで 0.15 以下 (多くは 0.01 未満) で,
r1 ≥ 17.8 では α=10 の行を除いて 0.94〜1.00 になる. r1 ≤ 0.562 の 14 マスのうち 11 マスでは最適な β が小さく
(r2* = σ/β* ≥ 34.8), サーバーがほとんど止まらないため, バーストの始まりですでに i+s ≥ n_target となり
P1 が発動しない. 発動確率は 1/(1+1/r1) よりも, 最適な β で決まるサーバーの残り方に左右される.

**注記 (範囲の端).**
(1) 地図 A の ρ_B=1.12 の r1=0.1 と 0.562 では, Base を含む全系列で β の最良点が範囲を 1 桁広げた後も
下端にある (β → 0, サーバーを落とさない方策が最良). この 2 マスでは全系列が同じ極限に近づくので,
相対差 (0.08% 以下) は β → 0 の極限どうしの比較になっている.
(2) n_target の最良点は, r1 ≥ 3.16 の多くのマスで上端 n_target=20 (=c, 取りうる最大) にある.
α=10 の行では下端 n_target=5 にあり, より小さい n_target は計算していない.
(3) γ の最良点は, P2 only の r1 ≥ 17.8 の多くのマスで上端 γ=1000 に, P1+P2 (protect) の多くのマスで
下端 γ=3 にある (γ=1 は P1 only (protect) の系列). P1+P2 (protect) は γ=1 と n_target=15 を含まないので
P1 only (protect) を包含せず, α=1, r1=3.16 のように P1 only (protect) の方が良いマスがある.
