## まとめ

数値はすべて上の表による. 改善 = −(相対差), 区分のしきい値は 0.1%. 35 マス.

- **(a)** ERP 最小点のブロッキング確率の Base に対する比の中央値は, P2 only 1.01, P1 only (protect) 0.99,
  P1+P2 (protect) 0.99 で, Base より高いマスはそれぞれ 21, 14, 12 マス (最大 1.63, 1.82, 2.54 倍).
  実験 7 の C1 (2.35 倍) ほど大きく上回るマスは少ない.
- **(b)** Base と同じ信頼性 (P ≤ P_ref) で Base より良い (改善 > 0.1%) マスは, P2 only 14, P1 only (protect) 16,
  P1+P2 (protect) 19 マス (最大 2.22%, 3.79%, 2.76%). ERP だけで改善が大きかったマスは (b) でもほぼ同じ大きさで
  残る (例: α=1, r1=3.16 の P1 only (protect) 3.79% → 3.79%, α=0.005, r1=17.8 の P1 only (protect) 2.90% → 2.68%,
  ρ_B=0.8, r1=17.8 の P1 only (protect) 2.81% → 2.81%). 一覧は「(b) で Base より良いマス」の表.
- **(c)** Base が P ≤ ε を満たせないマスは ε=1e-2 で 4, 1e-3 と 1e-4 で 5 (いずれも系列も満たせない).
  ε を小さくすると改善は大きくなる (ε=1e-3 で最大 P2 only 6.92%, P1+P2 (protect) 6.63%, P1 only (protect) 3.79%;
  ε=1e-4 で最大 12.32%) が, ε=1e-3 で Base の最良点が ERP 最小点と違う 7 マスのうち 5 マスは Base の最良点も
  粗い格子の点なので, この大きさは格子の粗さを含む. ε=1e-3 では α ≤ 0.02, r1 ≥ 17.8 で P1 only (protect) の
  改善が 0 になり (Base と同じく β の小さい点が最良), P2 を使う系列 (P2 only, P1+P2 (protect)) だけが改善する.
- **(d)** 3 指標の Base のフロンティアを全域支配するのは P1 only (protect) で 2 マス, P1+P2 (protect) で 1 マス,
  一部を支配するのはそれぞれ 30, 27 マス (P2 only は全域 0, 一部 25).
- **(e)** (Cost/λ_eff)×E[W] で改善 > 0.1% のマスは 15, 16, 19 マス (最大 2.55%, 3.80%, 2.85%) で, ERP とほぼ同じ.
- **ERP だけの判定から区分が変わった組** は 13 組で, 「改善 → 悪化」は ρ_B=0.6, r1=17.8 の P2 only
  (−0.46% → +0.59%) だけ, 「改善 → 同等」は ρ_B=0.8, r1=3.16 の P1+P2 (protect) (−0.21% → −0.05%) と
  α=1, r1=0.562 の P2 only (−0.16% → +0.06%), 残る 10 組は「同等 → 悪化」(最大 +0.78%) または
  「同等 → 該当なし」(ρ_B=1.12 の r1 ≤ 0.562) である.
- 注意: (b)(c) の最良点が粗い格子の点または β の範囲の端にある組が 133 組ある (一覧は上の表).
  このうち (b) で「改善」に入らない 25 組は, β を細かくすると区分が変わりうる (いずれも |差| ≤ 0.26%).
  改善が大きいマスの結論は, Predictive 側の格子を細かくしても改善が大きくなる方向にしか動かないので変わらない.
