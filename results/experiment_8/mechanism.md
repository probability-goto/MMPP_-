## 読み取れること

1. **β* の比 R と改善**: R と P1 only (protect) の改善の相関は, 全 35 マスで Pearson +0.785,
   Spearman +0.644, 改善が 0.5% を超える 12 マスで Pearson +0.666, Spearman +0.458 である.
   改善が 0.5% を超える 12 マスのうち 11 マスで R > 1 (β* が Base の 1.21〜3.01 倍; 残る 1 マスは
   B_alpha1 r1=100 の R=1) で, P1 only (protect) は通常期にサーバーを Base より早く切る点が最良になる.
2. **電力の内訳と位相ごとの内訳**: 改善の大きい点 (実験 7 の C1 と実験 8 の上位 3 マス) では,
   通常期 F=0 のアイドル E[I]_F0 が Base より 0.62〜0.91 台少なく (Cost_F0 が −0.10〜−0.20),
   バースト期 F=1 では起動中またはアイドルのサーバーが増えて Cost_F1 が +0.08〜+0.14 増える.
   差し引きの Cost は −0.38%〜−1.27% で, これら 4 点の ΔCost の主な成分はいずれも C_i·E[I] である
   (実験 7 の C3, C4 では C_s·E[S]).
3. **ERP の改善の出どころ**: 実験 8 の上位 3 マスでは ERP の改善 (2.83%〜3.79%) の大部分が
   E[W] の減少 (2.46%〜2.56%) から来ており, Cost の減少 (0.38%〜1.27%) は小さい.
   r1=17.8 の 2 マスではバースト期のブロッキング確率への寄与は逆に増えている
   (+1.2e-3〜+1.4e-3; Base は 1.0e-2〜1.1e-2). 実験 7 の C1 では E[W] の差は −0.18% で,
   改善 (1.16%) の大部分は通常期のアイドルを減らした Cost の減少 (−0.98%) による.
   つまり P1 only (protect) は, 通常期に早く切って電力を節約し, その分のバースト期の不足を
   事前セットアップと保護で補うことで, β の調整だけでは得られない組み合わせに到達している.
