# 実験設定の見直し仕様書 (実験 0〜4)

論理の流れは review_logic_flow.md. この仕様書は実験 0〜4 の設定, 出力, 確認する主張, 論文の修正を定める.
実験 5 (比較の地図) と実験 6 (頑健性) は設定を変えない (改善の仕組みの集計は別途).

## 共通の設定

| 項目 | 値 | 備考 |
|---|---|---|
| システム | c=20, K=200, b=5, μ=1 | 実験 4 は K を走査 |
| セットアップ率 | α=0.005 (1/α=200) | 実験 2 だけ α ∈ {0.005, 0.1, 1} |
| 振幅 | δ=0.6 | 実験 3-A だけ δ を走査 |
| Delayoff 率 (実験 1・3・4) | β_BE = (C_i/C_s)·α = 0.6α (α=0.005 で 0.003) | 損益分岐の固定値 |
| フェーズの長さ | r1 = α/σ, σ = α/r1 | 短 r1=0.1 (σ=0.05), 中間 r1=1 (σ=0.005), 長 r1=10^1.25≈17.8 (σ≈2.81e-4) |
| バースト期の負荷 | ρ_B = ρ(1+δ) | ρ_B=0.8 (ρ=0.5) と 1.12 (ρ=0.7) を代表に使う |
| 解法 | GTH | 各点で保存則, 流量バランス, min π ≥ 0, P_block > 0 を検査し CSV の check 列に残す |

r1 の短と長は比較の地図の格子 (r1 = 0.1, 17.8) にそろえる.

設定は変えない. 論文にパラメータを明記する: ベースモデル, 提案モデルとも α=0.1, β=0.005, δ=0.6, σ=0.1
(r1=1), 提案モデルは n_target=10, γ=5, 保護あり. 図: experiment_0_validation.pdf, experiment_0P_validation_protect.pdf.
2026-10-28 にベースモデルの DES の長さだけ変えた: ウォームアップ 1,000,000, 計測 4,000,000 イベント, 10 レプリケーション
(旧は 100,000 / 1,000,000 / 20 で, ウォームアップが遅い時定数 1/β の 5 倍に満たなかった. 旧の結果は archive/experiment_0_short_warmup/).
提案モデルは旧の設定のまま (同じ設定でやり直した結果は archive/experiment_0P_long_warmup/).

## 実験 1: ρ の走査

- 走査: ρ ∈ [0.1, 0.95] を 0.025 刻み (35 点. ρ_B=1 となる ρ=0.625 を含む).
- 条件: ポアソン (δ=0), δ=0.6 で r1 ∈ {0.1, 1, 17.8} の 4 本.
- 固定: α=0.005, β=0.003.
- 出力: results/experiment_1.csv, figures/experiment_1_traffic.{pdf,png} (4 指標 × 4 条件).
- 確認する主張:
  - V1: ρ_B < 1 (ρ < 0.625) の全点で, P_block は r1=0.1 の方が r1=17.8 より大きい.
  - V2: ρ_B > 1 では, どの r1 でも P_block がポアソンより 1 桁以上大きい.

## 実験 2: β の走査

- パート A (MMPP): β ∈ [1e-8, 1e2] の対数 41 点 × ρ_B ∈ {0.8, 1.12} × σ ∈ {0.05, 2.81e-4}
  (α=0.005 で r1 = 0.1, 17.8) × α ∈ {0.005, 0.1, 1}. σ を作業負荷の性質として固定し α を変える
  (α を変えると r1 も変わる).
- パート B (フェーズ別): 到着率を閑散期 λ_0 = ρ(1-δ)cbμ, 繁忙期 λ_1 = ρ(1+δ)cbμ のポアソン到着とし,
  ρ_B ∈ {0.8, 1.12} × α ∈ {0.005, 0.1, 1} で同じ β の格子を走査する. フェーズが十分長いときの近似.
- 出力: results/experiment_2.csv, results/experiment_2_phasewise.csv,
  figures/experiment_2_delayoff_erp.{pdf,png} (2×2: 行 ρ_B, 列 σ. 線は α. 損益分岐 β_BE(α) に印),
  figures/experiment_2_delayoff_pblock.{pdf,png} (同じ配置で P_block),
  figures/experiment_2_phasewise.{pdf,png} (ERP の β 依存, 閑散期と繁忙期).
- 確認する主張:
  - V3: α=0.005 で, 短フェーズ (r1=0.1) と ρ_B=1.12 の条件は ERP 最小の β が走査範囲の下限 (0 に近い).
    長フェーズかつ ρ_B=0.8 では内部に最小がある.
  - V4: パート B で, α=0.005 の閑散期の最適 β は繁忙期の最適 β より 2 桁以上大きい (繁忙期は下限).
  - V5: α=0.005 の全条件で, β_BE は ERP 最小の β より大きい.

## 実験 3: 振幅とフェーズの長さ

- 3-A: δ ∈ [0, 0.95] の 20 点 × r1 ∈ {0.1, 17.8} × ρ ∈ {0.5, 0.7}. α=0.005, β=0.003.
- 3-B: r1 ∈ [0.01, 1000] の対数 21 点 (σ = α/r1) × ρ_B ∈ {0.8, 1.12}. δ=0.6, α=0.005, β=0.003.
- 出力: results/experiment_3_delta.csv, results/experiment_3_r1.csv,
  figures/experiment_3_burstiness_delta.{pdf,png}, figures/experiment_3_burstiness_r1.{pdf,png}.
  旧 results/experiment_3_sigma.csv と figures/experiment_3_burstiness_sigma.* は消す.
- 確認する主張:
  - V6: ρ=0.7 では ρ_B=1 (δ≈0.43) を越えると P_block が急に大きくなる. ρ=0.5 ではそのような変化はない.
  - V7: ρ_B=1.12 では r1 が小さいほど P_block は小さい (短いバーストはバッファが吸収).
    ρ_B=0.8 では r1 が小さいほど P_block は大きい (セットアップが追いつかない).

## 実験 4: バッファ容量

- 走査: K ∈ {100, 200, 500, 1000} × ρ (実験 1 と同じ 35 点) × r1 ∈ {0.1, 17.8}. δ=0.6, α=0.005, β=0.003.
- 出力: results/experiment_4_short.csv, results/experiment_4_long.csv,
  results/experiment_4_split.csv (長フェーズ K=1000 の P_block を超過による棄却と立ち上がりによる棄却に分けた表.
  サーバーを切らない場合 β=1e-8 の P_block も持つ. 2026-10-28 追加),
  figures/experiment_4_K_sensitivity_{short,long}.{pdf,png}.
  旧 results/experiment_4_{weak,medium,strong}.csv と figures/experiment_4_K_sensitivity_{weak,medium,strong}.* は消す.
- 確認する主張:
  - V8: 長フェーズかつ ρ_B > 1 では, K を 100 から 1000 にしても P_block は 2 倍も下がらない.
    短フェーズ, または ρ_B < 1 では大きく (1 桁以上) 下がる点がある.
  - K=200 の行は実験 1 の同じ条件と一致する.

確認する主張が成り立たない場合は, 論文を書き直す前に報告する.

## 確認の結果 (2026-10-25)

全点で検査 (保存則, 流量バランス, min π ≥ 0, P_block > 0) の違反なし (実験 1: 140 点, 2: 1008 点, 3: 122 点, 4: 280 点).

| 主張 | 結果 | 内容 |
|---|---|---|
| V1 | 成立 | ρ_B < 1 の全点で r1=0.1 の P_block > r1=17.8 の P_block. ただし r1=1 がさらに大きい |
| V2 | 成立 | ρ_B > 1 の全点で, どの r1 でもポアソンの 10 倍以上 |
| V3 | 一部不成立 | 短フェーズ・ρ_B=1.12 は下限. 短フェーズ・ρ_B=0.8 は内部 (5.6e-5. 平均待ち時間はフェーズの長さの約 900 倍で, 実質的に切らない). 長フェーズ・ρ_B=1.12 も内部 (1.8e-3) |
| V4 | 成立 | 閑散期 3.2e-4, 繁忙期は下限 |
| V5 | 成立 | α=0.005 の 4 条件すべてで β_BE > ERP 最小の β |
| V6 | 不成立 | ρ_B = 1 で P_block が急に変わる点はない. 長フェーズで ρ_B > 1 なら超過分の割合が下限 |
| V7 | 一部不成立 | どちらの ρ_B でも r1 = 0.18〜0.56 で最大の山形. r1 → ∞ でフェーズ別の近似の値に近づく |
| V8 | 成立 | 長フェーズ・ρ_B>1 で K=100/1000 の比 1.81 以下. 短フェーズでは 1 桁以上. 長フェーズは ρ_B<1 でも K ≥ 200 でほぼ下がらない |
| K=200 と実験 1 | 一致 | 相対差 0 |

不成立の項目は細部の予想で, 結論の骨格 (review_logic_flow.md の (a)(b)(c)) は保たれた. 論理の流れは実際の結果に合わせて直した.
